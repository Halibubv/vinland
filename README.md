# ВИНЛАНД / VINLAND

Учебное веб-приложение для учёта силовых тренировок и дневника питания с КБЖУ. Проект развивается как курсовая работа и будущий проект для портфолио.

## Текущий статус

Проектирование интерфейса. Ведётся подготовка визуальных референсов; работающего приложения и инструкции запуска в этом репозитории пока нет. Технологический стек ещё не зафиксирован.

## Планируемые возможности

- Главная: полезные материалы и быстрые действия (концепция расширения).
- Тренировки: сохранённые занятия, упражнения, подходы, повторения и вес.
- Питание: продукты, граммовки, приёмы пищи и суточные итоги КБЖУ.
- Профиль: личная сводка, настройки, ручные цели КБЖУ и переход к статистике.
- Вход и регистрация.
- Администрирование справочников упражнений и продуктов.

## Структура

- `docs/` — описание проекта и подготовленная документация.
- `design/` — правила оформления и место для проверенных референсов.

## Ближайшие этапы

1. Проверить комплект desktop- и мобильных макетов по ТЗ.
2. Подготовить редактируемые макеты и единые компоненты.
3. Утвердить стек и реализовать минимальную рабочую версию.
4. Добавить тесты, инструкции запуска и демонстрацию.

## Работа с материалами

Переписки, персональные данные из учебных документов, секреты и временные файлы не входят в репозиторий. Визуальные концепты не являются реализованными функциями; любые числа на будущих макетах — демонстрационные. Перед публикацией ассетов проверяются права на их использование.
