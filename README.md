# ВИНЛАНД / VINLAND

Веб-приложение для учёта силовых тренировок и дневника питания с КБЖУ:
тренировки с подходами и весом, приёмы пищи по граммовкам, личные цели,
статистика и администрирование справочников. Курсовой проект и проект для
портфолио.

**Стек:** React 19 + обычный CSS (Vite), PHP 8.4 без фреймворка, PostgreSQL 17.

Приложение работает. Описание, скриншоты, устройство кода, запуск и тесты —
в [app/README.md](app/README.md).

## Структура репозитория

- `app/` — приложение: интерфейс, PHP API, миграции базы, тесты.
- `docs/` — описание проекта.
- `design/` — правила оформления. Макеты для компьютера, планшета и телефона
  сделаны в Figma, по ним свёрстан каждый экран.

## Работа с материалами

Переписки, персональные данные, секреты и временные файлы в репозиторий не
входят. Данные на скриншотах — демонстрационные (`app/database/seed-demo.php`).
