# Документация

Здесь будут размещаться проверенные требования, модель данных и пользовательские сценарии.

Исходные учебные документы пока не перенесены. Перед добавлением убрать персональные сведения, переписки, подписи и лишние вложения. Схема БД должна быть проверена на актуальность; не загружать дампы с реальными пользовательскими данными.

Текущий согласованный маршрут: Главная → Тренировки → Питание → Профиль. Статистика открывается из профиля. Администрирование справочников доступно только администратору.
