# Дизайн ВИНЛАНД

Статус: подготовка статичных референсов, не готовый интерфейс.

## Согласованное направление

- Логотип с горами.
- Холодная северная палитра: графит, фьорды, светлые акценты.
- Атмосферная главная с выразительными заголовками; спокойные рабочие экраны тренировок, питания и профиля.
- Единое меню: Главная → Тренировки → Питание → Профиль.
- На ПК навигация сверху, на телефоне снизу.
- Лендинг до входа и главная внутри приложения — разные страницы.

## Подготовка материалов

Референсы будут добавлены после проверки текста, навигации, чисел, прав на ассеты и отсутствия личных данных. Исходные изображения пока не загружены. При переносе в редактируемые макеты нужны реальные фоновые изображения, логотип, единый набор иконок и шрифты; картинка не гарантирует точное воспроизведение.
